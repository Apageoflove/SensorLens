没有加载数据

把图片、JSON（内参、外参、位姿、标注）和可选的点云一起选上，或直接选整个文件夹 / zip。 图片和 JSON 不必分开传：JSON 里写的图片路径（或文件名、相机名）会自动对上。 分几次选的文件会累加；漏了图片，可以之后“追加到当前”会话。

文件夹里的无关文件（文档、日志、缓存、隐藏文件等）会自动忽略，不会上传。 数据很大（几 GB 以上）时用“打开本机目录”，原地读取不复制。只有图片也能浏览。
